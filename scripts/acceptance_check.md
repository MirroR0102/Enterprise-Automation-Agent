# 验收记录

目标句：

`帮我搜索2026AI行业新闻，再查询本月销售总额，计算同比增长率，生成一份运营周报markdown`

在已配置 `DEEPSEEK_API_KEY`（及可选 `TAVILY_API_KEY`）时：

1. `python scripts/init_db.py`
2. `python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`
3. 浏览器打开 http://127.0.0.1:8000/login.html ，用 `ops` / `ops123` 登录
4. 发送验收句（发送成功后输入框应清空）
5. 时间线应出现搜索 / mysql_query / calculator；**入参/返回默认展开可见**
6. 最终右侧分屏预览 Markdown；状态为 **已完成**
7. 顶栏「过往周报」可看到刚生成的记录
8. 点取消可终止**进行中**的任务；成功结束后取消按钮灰色
9. 左侧可切换「知识库问答」占位页
10. `pytest -q` 全绿（测试强制 mock DB）

## 多轮记忆演示（同会话）

1. 在同一会话先生成一份「上周」完整周报（或任意完整周报）。
2. **不要**点「新开对话」，继续发送：

`记住刚才上周周报的章节结构和写法。请用同样的格式生成「本周」运营周报 markdown，不要改栏目顺序。`

3. 会话短 id 应保持不变；Agent 应尽量沿用上一份结构（依赖 MemorySaver + 同 `session_id`）。
4. 需要清空上下文时再点「新开对话」。

## 设置

- 点击左下角头像 → 可改昵称（上行显示）；登录用户名在下行只读。
- 周报保存目录偏好仅作说明，实际写文件仍在服务端 `reports/`。

无 Tavily 时，搜索工具会返回配置错误文案，Agent 应说明原因而不是编造新闻。
无 DeepSeek 时，页面任务会失败；单测仍可全部通过。

MySQL：`USE_MOCK_DB=false` 时业务数据在主库 `enterprise_ops`；每位用户另有分库 `eoa_u_{id}` 存对话与过往周报。
